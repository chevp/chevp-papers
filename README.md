# chevp-papers

A working notebook of short, abstract-style notes on tools, process, and AI-assisted software development. One idea per paper.

Live at <https://chevp.github.io/chevp-papers/>.

## Structure

- `index.html` — Paper Hub (volume index)
- `paper-NNN-<slug>.html` — individual papers, each self-contained

Static HTML, no build step. Open files directly in a browser, or serve the folder with any static server.

## Conventions

- One file per paper. Self-contained styles. Google Fonts only (EB Garamond, Inter, JetBrains Mono).
- IDs: `PPR-NNN` for papers, `NOTE` for shorter notes.
- Each paper carries an Abstract, numbered sections, a §6 Kill Criteria block, and References.
- Papers are citable but not finished. The point is to think out loud, in public, in a form that can be refuted.
